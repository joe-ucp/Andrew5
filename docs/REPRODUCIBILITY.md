# Reproducibility

The public entry point is `python code/reproduce.py`. Run it from the repository folder with Python 3.12 and [pinned dependencies](../code/requirements.txt). [GETTING_STARTED.md](GETTING_STARTED.md) provides an external-environment setup.

## Choose the scope

| Command | Inputs | What it establishes |
|---|---|---|
| `check` | Files listed in `PUBLIC_FILES.json` and registered compact scientific inputs | Included code, documentation, artifacts and scientific inputs match their declared checksums; no data download or scientific computation. |
| `demo --output-dir PATH` | Synthetic inputs generated by the tool | The supplied-signature diagnostic runs and produces inspectable reports. |
| `influence --output-dir PATH` | Included compact gene contributions | Four exploratory arithmetic influence tables reproduce from the retained contributions. |
| `stages` | Included stage definitions | Lists available scientific computations, inputs and prerequisites. |
| `stage NAME --data-root PATH --output-dir PATH` | Registered raw data or caches for the named stage | Executes that declared computation into external storage and reports its comparisons. |
| `stage all --data-root PATH --output-dir PATH` | Registered source files and any verified parser caches | Executes the ordered chain in one external workspace, requiring newly generated dependencies from earlier stages. |

Use `python code/reproduce.py --help` and each command's help for exact options. Use a platform-native absolute path for external inputs and outputs. Output folders must be outside the repository. Existing results are not silently overwritten.

## Scientific reconstruction

```sh
python code/reproduce.py stages
python code/reproduce.py stage NAME --data-root /absolute/external/data --output-dir /absolute/external/run
```

Replace `NAME` with a stage printed by the listing. A single stage may reuse registered retained scientific prerequisites, with their origins recorded. A computation from registered sparse caches does not imply that raw-matrix parsing was repeated. `--fetch` downloads missing registered public source files only, checking their pinned hashes; it does not download derived outputs.

For example, run the complete independent human-islet state and thinning benchmark from its four registered Baron count files and the included fixed program prerequisites:

```sh
python code/reproduce.py stage independent --data-root /absolute/external/baron-data --output-dir /absolute/external/independent-run --fetch
```

This standalone run produces six comparison tables and fresh per-cell arrays. Inspect `receipts/independent.json` for input origins and numerical comparisons. It does not regenerate the earlier feature-selection stages or establish a complete 18-stage rerun.

For the complete ordered chain, choose a new external output folder:

```sh
python code/reproduce.py stage all --data-root /absolute/external/data --output-dir /absolute/external/full-run --fetch
```

Omit `--fetch` when the sources are already present. The source registry contains 56 downloadable computational source files. The chain regenerates derived scientific dependencies under the output folder and rejects a missing generated prerequisite rather than falling back to an old result. Hash-verified source parser caches may still be reused. This starts from deposited processed matrices, not FASTQ alignment. The input-origin records distinguish reused inputs from generated outputs.

The listing gives the exact source groups and table comparisons for each of the 18 stages. A stand-alone stage expects its declared prerequisites to be available; use the complete chain to generate the scientific dependencies in order.

Outputs include compact tables under `evidence/`, bulk intermediates under `data/`, figures under `manuscript/figures/`, per-stage records under `receipts/`, and `execution_inputs.json`, all beneath the chosen external output folder. Stage records identify input origins, parameters, code and comparisons. Existing stage receipts or outputs cause an error instead of an implicit overwrite.

Declared numerical tables are compared with retained results using relative tolerance `1e-12` and absolute tolerance `2e-14`; exact byte equality is reported separately. Only the native independent `signed_log1p_CPT10K` AUROC and alpha/beta score-depth Spearman metrics have a narrowly scoped alternative: integer counts must certify exact score cancellation, fresh per-cell arrays must reproduce the fresh metric, and both retained and fresh metrics must lie within the resulting roundoff rank envelope. [Numerical comparison](NUMERICAL_COMPARISON.md) gives the observed cause, formulas, checks and report fields. Scores and scientific tables are not rounded, refitted or changed. All other fields retain the ordinary tolerance. The `population_audit` elapsed-seconds column is excluded from numerical comparison. Platform line endings and compressed wrapper metadata can change bytes without changing decoded scientific values; the output records distinguish these cases.

The analysis spans reference calibration, drug-donor score components, true finite-library thinning, independent labelled state controls, scorer/program comparisons, threshold transport, gene contributions and conditional nuisance checks. The [results index](RESULTS.md) maps outputs to the paper. Original numerical definitions, seeds, gene universe, block denominators and sample mappings are scientific inputs and remain explicit.

Bulk sources and caches are not bundled. The principal original matrices and metadata total about 1.87 GB compressed, with additional storage needed for sparse caches and outputs. The four Baron human count files total about 25 MB compressed. The original computations used a 32 GB RAM computer and processed large primary libraries sequentially without a GPU. Runtime depends on CPU and storage.

## External storage configuration

Data-dependent tools accept explicit absolute locations. Where a data-root resolver is used, precedence is the explicit option, then `STRIKE007_CACHE`, then optional user configuration. There is no built-in public machine path.

Configuration lives outside the repository at `%LOCALAPPDATA%/UCP/STRIKE007/storage.json` on Windows or `$XDG_CONFIG_HOME/ucp/strike007/storage.json` on Linux, defaulting to `~/.config/ucp/strike007/storage.json`. `STRIKE007_STORAGE_POLICY` may name another absolute external JSON file. [storage.example.json](../storage.example.json) documents the format. Local allowed-root restrictions remain enforced when explicit paths are supplied. Repository overlap, traversal and resolved links back into the repository are rejected.

## Numerical and interpretive checks

`python code/run_tests.py` checks synthetic rank ties, sparse/dense agreement, gene mapping, count thinning, detection probabilities, score components, threshold decisions, influence arithmetic and path handling. The optional retained zero-null regression is requested explicitly:

```sh
python code/run_tests.py --external-data --data-root /absolute/external/data
```

Missing requested external fixtures fail clearly. Platform-specific symlink tests may skip when the host lacks the required capability. Test success is separate from reproduction of research outputs.

TSV numerical values and source hashes support reproducibility; execution timestamps and compressed-file wrapper timestamps are not biological observations. For the original signed-rank score, exact half-rank arithmetic preserves mathematical zeros. The separate signed-log comparison rule above addresses certified cancellation in that alternative scorer. Repeated thinning draws measure conditional sampling variability and do not increase the number of donors.

The influence calculation subtracts already-retained centered gene contributions with the original universe and denominators fixed. It does not rerank, refit or simulate gene deletion. Its donor-specific ordering is outcome-informed and exploratory. All donors and all requested subtractions remain available; these results do not replace the failed matched-program specificity control.

Reproducing code does not establish ancestry, secretion, immune protection or clinical efficacy. The paper and [results guide](RESULTS.md) state the limits of each measurement.
